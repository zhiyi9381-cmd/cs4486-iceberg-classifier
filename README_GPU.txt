# GPU Training Instructions

## Overview

The final model (submission v8) is a VGG9 convolutional network trained on GPU, followed by a LightGBM meta-learner that consumes CNN predictions together with incident-angle features. This document describes how to reproduce the final GPU pipeline.

## Requirements

- NVIDIA GPU with at least 6 GB of memory (8 GB recommended)
- Python 3.10 or newer (3.11 / 3.12 / 3.13)
- CUDA toolkit and NVIDIA driver installed

## Setup

1. Extract the `method2` folder to any path; `<METHOD2>` below refers to this directory.
2. From a terminal, change into `<METHOD2>`.
3. Install the GPU build of PyTorch matching your CUDA version (install only one line):
   - CUDA 11.8: `pip install torch --index-url https://download.pytorch.org/whl/cu118`
   - CUDA 12.1: `pip install torch --index-url https://download.pytorch.org/whl/cu121`
   - CUDA 12.4: `pip install torch --index-url https://download.pytorch.org/whl/cu124`
   - To check your CUDA version, run `nvidia-smi` and read the version in the top-right corner.
4. Install the remaining dependencies:
   - `pip install -r requirements_gpu.txt`

## Reproduction levels

This repository supports \emph{full re-training from source}. It does \emph{not} provide a ready-to-replay set of saved weights, so you cannot reproduce the exact v8 predictions without re-running training:

- **Level 1 - Re-train from official data (supported).** With the official `train.json` / `test.json` in `data/`, run Step 1 then Step 2 below to rebuild all intermediate assets and the final submission. This reproduces the method, but scores may differ slightly across hardware and library versions.
- **Level 2 - Replay saved weights (not supported).** The final VGG9 checkpoints and the pretrained encoder weights are not committed, so exact score replay is not possible from this repository alone.

## Reproducing the final pipeline (v8)

The final `gpu_pipeline_v8.py` depends on a nested out-of-fold (OOF) cache of CNN predictions that is produced by an earlier stage. This OOF cache is a \emph{mandatory prerequisite} for Step 2. Run the stages in order.

### Step 1 - Generate the nested OOF cache

The meta-learner consumes CNN predictions as features. Those training-side predictions are generated by a nested 5x5 cross-validation loop so that no sample's own label leaks into its feature vector.

```
python scripts/p4_nested_oof.py
```

This writes `oof/nn_pred_nested_<run_id>.npz` (plus a `.meta.json` sidecar). The v8 pipeline loads the most recent `oof/nn_pred_nested_*.npz`, so this file must exist before Step 2.

### Step 2 - Run the final GPU pipeline

```
python scripts/gpu_pipeline_v8.py
```

The full run takes about 30-60 minutes depending on the GPU. The script performs:

1. Self-supervised denoising pretraining of the VGG9 encoder on all images.
2. One round of pseudo-labeling on the test set using a pure CNN (no angle priors).
3. Retraining the VGG9 on the labeled set plus pseudo-labels (5 seeds x 5 folds, with 4-way flip test-time augmentation).
4. Combining the VGG9 predictions with the incident-angle features and a LightGBM meta-learner.
5. Writing the output to `submissions/submission_v8_*.csv`.

## Notes

- Missing OOF cache: if Step 2 fails with a `FileNotFoundError` for `oof/nn_pred_nested_*.npz`, run Step 1 first.
- CUDA / PyTorch version error: the PyTorch CUDA version does not match the driver; reinstall PyTorch with the matching `cu118` / `cu121` / `cu124` index.
- Out of memory: reduce `BATCH = 32` to `BATCH = 16` in `scripts/gpu_pipeline_v8.py`.
- Faster run: shorten `SEEDS = [42, 7, 2024, 1234, 0]` to `[42, 7]` (results will be slightly worse).
- Without a GPU, the script falls back to CPU (much slower) and prints a warning; this does not affect correctness.

## Final model weights

The final trained checkpoints are not committed to the repository because they are large and depend on the local CUDA environment. The pipeline is fully re-runnable from source with the steps above. Reproduced scores may differ slightly across CUDA / PyTorch versions and GPU hardware due to non-deterministic floating-point operations.
